# Akshaya Reddy Portfolio

Modern recruiter-friendly React portfolio built with Vite, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Before deploying

1. Replace `public/resume.pdf` with your real resume.
2. Replace `your-email@example.com` in `src/App.jsx` with your actual email.
3. Add real live-demo URLs to the `projects` array where available.
4. Review internship descriptions and dates.
5. Deploy to Vercel, Netlify or GitHub Pages.

## Main files

- `src/App.jsx` — sections/components and portfolio data
- `src/styles.css` — complete responsive styling and animations
- `src/main.jsx` — React entry point
